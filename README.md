# НАНОБОТЫ

Сайт анимационного образовательного проекта ООО «4МЕДС».

## Публикация на GitHub Pages

Готовая публичная версия находится в `docs/`. В Settings → Pages выберите **Deploy from a branch**, ветку `main` и каталог `/docs`, затем Save. Дополнительная сборка не требуется.

Веб-версия содержит главную страницу с каруселью постеров, карточки персонажей, карту тела, ссылки на серии и соцсети.

## Как обновить серии и новости

Для GitHub Pages отредактируйте `docs/content/entries.json` через GitHub. Это список записей; пустой список `[]` показывает ссылки на официальные каналы. Не публикуйте черновики или конфиденциальные материалы в публичном репозитории.

Запись серии:
```json
{"id":1,"kind":"episode","title":"Название серии","summary":"Краткое описание","body":"","date":"2026-09-18","cover":"./art/poster.jpg","video_url":"https://vk.ru/nanobotsmult","published":1}
```
Для новости используйте `kind: "news"`, текст в `body`, и пустой `video_url`. Реальные ссылки на видео и тексты добавляет редактор. Видео размещаются на внешних площадках.

При пересборке источником контента служит `public/content/entries.json`: перенесите туда изменения из `docs/content/entries.json`, иначе они будут заменены.

## Исходный сайт и редакция

Папки `app/`, `components/`, `lib/`, `public/` содержат исходники, включая текущую серверную редакцию `/admin`. Она использует Cloudflare D1/R2 и авторизацию Sites. GitHub Pages обслуживает только публичную статическую версию; редакция на нём не запускается. Для её переноса на другой сервер нужно подключить базу, хранилище и заменить авторизацию.

Данные из рабочей D1-базы и файлы из R2 в этот экспорт не включены. Публичная версия пока использует пустой каталог серий и новостей со ссылками на официальные каналы.

## Пересборка публичной версии

Требуется Node.js 22.13 или новее и зависимости из `package.json`.
```sh
npm install
npm run build:pages
```
После сборки сохраните изменения в `docs/` в GitHub. `scripts/build-pages.mjs` собирает те же компоненты главной страницы; серверный код не попадает в публичный JavaScript.

Изображения, персонажи, логотип и материалы проекта предоставлены правообладателем. Публичность репозитория не предоставляет лицензию на их использование. Лицензии зависимостей и сторонних компонентов сохраняются.
