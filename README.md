# НАНОБОТЫ

Сайт анимационного проекта ООО «4МЕДС»: https://nanoboti.ru/.

## Публикация на GitHub Pages

Публичная версия находится в `docs/`. GitHub Pages публикует ветку `main`, каталог `/docs`; домен задан в `public/CNAME` и `docs/CNAME`.

Исходники согласованного дизайна новой главной находятся в `pages/homepage/`. Это HTML, CSS и JavaScript: шрифт и изображения размещены вместе с сайтом. Серверная среда и React для главной не требуются.

```sh
node scripts/build-pages.mjs
```

Скрипт переносит `public/` и `pages/homepage/` в `docs/`, сохраняя существующие маршруты и ресурсы. После сборки нужно сохранить исходники и изменённые файлы `docs/` в Git и отправить их в `main`.

## Главная страница

- `pages/homepage/index.html` — разделы, навигация, ссылки и метаданные.
- `pages/homepage/series.css` — оформление и адаптивность.
- `pages/homepage/app.js` — меню, переключение героев, подробные описания и карта тела.
- `pages/homepage/characters.js` — утверждённые описания персонажей.
- `pages/homepage/motion.js` — движение клеток крови и управление анимацией. Учитывает предпочтение уменьшенного движения и останавливает рисование вне экрана.
- `pages/homepage/assets/` — иллюстрации, портреты, логотипы, иконки и Geologica. Лицензия шрифта: `assets/fonts/OFL-Geologica.txt`.

На главной: пять героев, четыре второстепенных персонажа, карта Петра с 11 интерактивными подписями, восемь каналов, образовательный раздел, новости ВКонтакте и информация для партнёров. Переходы к викторине убраны; отдельная страница `/quiz/` сохранена для старых ссылок.

Блок «А что за кадром?» ведёт на https://vk.ru/nanobotsmult. Telegram остаётся среди восьми официальных каналов.

70+ млн просмотров и 100 тыс. подписчиков — совокупные показатели команды, а не текущие данные API. Существующий счётчик Яндекс.Метрики сохранён и запускается только на домене проекта.

## Медиакит и другие страницы

`/mediakit/` остаётся отдельной страницей: исходники в `public/mediakit/`, публикация в `docs/mediakit/`. Чтобы изменить медиакит, редактируйте его исходники и повторите сборку.

`public/mediakit/brand.css` объединяет оформление медиакита с главной: общий шрифт Geologica из `/assets/fonts/`, цвета, кнопки и переходы между разделами. Отдельный блок карточек команды удалён.

Контакт: Анастасия Валикова, `valikova@4meds.ru`. Форма медиакита составляет письмо и открывает почтовое приложение; автоматической отправки и хранения данных на сервере нет.

`public/content/entries.json` и `docs/content/entries.json` сохранены. Новая главная отправляет зрителей на официальные площадки; прежний каталог записей автоматически не отображается.

## Существующая автоматическая статистика

Задание `.github/workflows/update-stats.yml` продолжает обновлять публичные снимки `public/content/stats.json` и `docs/content/stats.json`. Оно использует GitHub Secrets `YOUTUBE_API_KEY` и `VK_ACCESS_TOKEN` через официальные API. Ключи не должны попадать в файлы или переписку. На новой главной этот JSON не используется.

Проверка: `node --test scripts/update-stats.test.mjs`. Запуск через Actions → Update audience statistics → Run workflow. Плановое обновление — на 17-й минуте каждого часа; GitHub может задерживать запуски.

## Предыдущая реализация

`app/`, `components/`, `lib/` и `pages/main.tsx` сохранены как предыдущая React/Vinext-реализация. Команда `build:pages` больше их не собирает. Серверная редакция `/admin` зависит от Cloudflare D1/R2 и авторизации Sites и не работает на GitHub Pages. Старый партнёрский компонент с FormSubmit не используется новой главной.

## Права

Изображения, персонажи, логотип и материалы проекта предоставлены правообладателем. Публичность репозитория не предоставляет лицензию на их использование. Лицензии зависимостей и сторонних компонентов сохраняются.
